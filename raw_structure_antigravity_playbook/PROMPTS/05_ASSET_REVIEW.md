# Prompt 05 --- Asset, font, and media review

Audit every image, video, font, icon, and other nontrivial asset in the
project.

For each asset: 1. Identify its source and local path. 2. Record
creator/source URL and licence/permission status in
`ASSET_REGISTER.csv`. 3. Check whether modification, commercial use, and
attribution are allowed. 4. Replace assets with unknown or incompatible
rights status with original or appropriately licensed alternatives. 5.
Check resolution, crop, focal point, file size, format, and responsive
behavior. 6. Optimize images and video; reserve dimensions to avoid
layout shifts. 7. Use local files where practical and avoid broken
remote URLs. 8. Do not use an asset that falsely implies the client
built a project or holds a certification. 9. Do not use the original
website's logo, copy, photos, video, or font files for client production
unless permission/licensing is confirmed.

Report assets with unresolved rights status. Do not label an asset
"free" without evidence from the relevant licence.
