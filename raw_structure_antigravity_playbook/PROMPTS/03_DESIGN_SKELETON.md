# Prompt 03 --- Recreate the static layout first

Prerequisites: architecture approved.

Read `REFERENCE_AUDIT.md` and `DESIGN_SYSTEM.md`.

Tasks: 1. Convert the verified section inventory into a component plan.
2. Define CSS design tokens for colors, typography, container widths,
gutters, spacing, and breakpoints. 3. Implement the page sections in the
correct order with responsive markup. 4. Match section heights, text
scale/line breaks, alignment, whitespace, borders, and image aspect
ratios as closely as observation allows. 5. Use licensed/original
temporary imagery and record it in `ASSET_REGISTER.csv`. Do not assume
reference-site assets may be reused. 6. Keep headings and content
readable without animation. 7. Do not implement complex scroll motion
yet. 8. Check desktop, tablet, and mobile layouts; fix overflow and text
clipping. 9. Compare browser screenshots with the reference at the same
viewport where possible. 10. Update `docs/reference-notes.md` with known
visual differences.

Do not proceed to complex animations until the static composition is
reviewed. Report files changed, screenshot evidence, actual tests, and
unresolved mismatches.
