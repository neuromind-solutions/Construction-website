# Prompt 01 --- Inspect the RAW STRUCTURE reference before coding

Reference: https://rawstructure.framer.website/

Read `REFERENCE_AUDIT.md` and `PROJECT_BRIEF.md`.

Use the browser available to you, if available, to inspect the public
reference through normal navigation. Do not attempt to bypass
protections or retrieve private source/project files.

Tasks: 1. Inspect the full page from top to bottom at desktop viewport
size. 2. Repeat at a mobile viewport if browser tooling supports it. 3.
Record section order, approximate dimensions, typography, color,
imagery, spacing, and responsive changes. 4. Test visible buttons,
links, hover states, galleries, sticky/pinned behavior, and scrolling.
5. Scroll both downward and upward; record whether animations reverse,
scrub with scroll, or play once. 6. Record only what was directly
observed as `VERIFIED`. Label all other details `UNVERIFIED`. 7. Save
notes to `docs/reference-notes.md`; update `REFERENCE_AUDIT.md` or add a
structured section/interaction inventory. 8. Capture screenshots only if
the browser tooling supports it and save them locally. Record viewport
dimensions and approximate scroll position. 9. Do not code the website
in this phase.

Known leads to verify, not assume: character headline animation,
blueprint grid/drawing, blueprint-to-building transition, stacked/pinned
imagery, rotating concrete block, animated statistics, project gallery,
marquee, custom cursor.

Deliver a prioritized feature inventory: - Must reproduce for
fidelity. - Nice-to-have. - Unverified / needs owner input. - Cannot
inspect or blocked.

At the end, stop and ask for review of the audit before implementation.
Do not claim to have opened the site if browser access was unavailable.
