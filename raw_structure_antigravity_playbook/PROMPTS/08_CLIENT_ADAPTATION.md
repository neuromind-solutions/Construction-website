# Prompt 08 --- Transform the study into an original client website

Use the reference implementation as a technical learning base, but
create a distinct client-ready construction company website.

First ask for or locate owner-approved: - Company name and logo. - Brand
colors and typography preferences. - Actual services and regions
served. - Real project images and descriptions. - Verified company
metrics, credentials, certifications, and testimonials. - Phone, email,
address, WhatsApp, and contact destination. - Required pages, SEO
priorities, and language/localization needs.

Then: 1. Replace reference brand identity, copy, and non-licensed
assets. 2. Do not invent project details, claims, years of experience,
client logos, or testimonials. 3. Preserve animation techniques only
where they support the client's content and user goals. 4. Make
enquiries functional only after the owner approves the submission
destination and privacy approach. 5. Add metadata, accessibility,
responsive behavior, and performance checks. 6. Verify licences for
every production asset. 7. Keep deployment and external integrations
disabled until explicitly approved. 8. Produce an original design
rationale and a final acceptance report.

Do not simply reskin the reference with the client's logo if the
resulting page would still reproduce distinctive protected expression or
use assets without permission. Make deliberate design changes and
document them.
