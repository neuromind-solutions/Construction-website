# Install into an Antigravity workspace

1.  Extract this archive into a local project folder.
2.  Open the folder as a workspace in Antigravity.
3.  Keep `AGENTS.md` at the project root and preserve `.agents/rules/`.
4.  Start with `PROMPTS/00_START_HERE.md`, then proceed in order.
5.  Review each phase's report before allowing the next phase.
6.  No deployment or remote push is authorized by this pack.
