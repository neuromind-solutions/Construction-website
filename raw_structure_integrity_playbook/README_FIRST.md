## 🏗️ What This Playbook Contains

This directory is an authoritative, complete project package ready for execution in Antigravity:

- **`PROJECT_BRIEF.md`:** Comprehensive verified project scope, 17-route site matrix, and architecture boundaries.
- **`AGENTS.md`:** Persistent workspace agent instructions ensuring rigorous, disciplined development.
- **`ARCHITECTURE.md`:** Next.js App Router structure, component hierarchy, and typed data architecture.
- **`REFERENCE_AUDIT.md`:** Detailed empirical audit of every page, section, coordinate, and breakpoint.
- **`DESIGN_SYSTEM.md`:** Complete token specification (Asphalt Black, Concrete Charcoal, Safety Orange, Anton & Archivo typography).
- **`ANIMATION_SPEC.md`:** Engineering specifications for the diagonal marquee, horizontal drag slider, level timeline switcher, and metric counters.
- **`ASSET_REGISTER.csv`:** Complete provenance register for open-source fonts, CC0 images, and SVG blueprint assets.
- **`QA_ACCEPTANCE.md`:** Quality gates, test commands, and multi-device acceptance criteria.
- **`SECURITY_AND_GIT.md`:** Local-first guardrails and safety protocols.
- **`SOURCES.md`:** Reference URLs, official documentation links, and typography sources.
- **`DESIGN_DECISIONS.md`:** Architectural decision log documenting stack choices.
- **`INSTALL.md`:** Workspace startup instructions.
- **`screenshots/`:** 11 high-resolution reference screenshots captured live from `rawstructure.framer.website`.
- **`docs/full_site_inventory.md`:** Complete verbatim textual content of all 17 pages.
- **`docs/search_index.json`:** Extracted site search index containing all routes, headers, and paragraphs.
- **`.agents/rules/`:** Scoped Antigravity behavior rules for frontend, animation, assets, and testing.
- **`PROMPTS/`:** Sequenced prompt files (`00` to `09`) for executing each development phase in Antigravity.
